# Agent Recipes kit, by Naturate

Sixteen AI build patterns. Each folder holds a `SKILL.md` your coding agent can follow and
small reference files you can read in a few minutes.

## How to use it

1. Pick the one folder that matches a job you have now.
2. Read its guide at https://agentrecipes-ai.vercel.app/docs first. The guide says what
   the pattern is for, what has been tested and what has not.
3. Copy the folder into your project's skills directory, or point your coding agent at
   `SKILL.md`, and ask it to adapt the pattern to your codebase.
4. Try it with synthetic data before it touches anything real.

A skill file is a set of instructions. It grants no permissions and starts nothing on
its own.

## What is inside

| Folder | Use it to |
|---|---|
| service-to-mcp | Make an existing service usable by AI agents |
| cross-agent-handoff | Get two assistants working on the same task |
| scoped-autonomous-operations | Run a small daily desk that prepares drafts for review |
| pointmoon-grounding | Give an agent sourced, time-stamped context about the world outside |
| ai-native-admin | Build admin tools that people and agents share |
| llm-prompt-ops | Keep an AI feature reliable while you keep changing the prompt |
| grounded-generation | Make a model talk about the real world without inventing facts |
| voice-ai-pipeline | Start AI voice playback in seconds |
| shared-agent-memory | Give agents a memory that survives every session |
| agent-worker-fleet | Run several agents on real work unattended |
| two-agents-one-repo | Run two coding agents in one repository without losing work |
| agent-safe-releases | Let agents ship without breaking production |
| prove-a-change | Prove an AI change is better before it ships |
| honest-agent-reports | Stop agents overstating what they did |
| agent-lanes | Give each agent a lane |
| when-to-say-nothing | Teach an assistant when to say nothing |
