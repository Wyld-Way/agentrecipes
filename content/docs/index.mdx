Use the library to connect an existing service, coordinate a small workflow, build an admin tool, or improve an AI feature you already run.

Each guide should explain the result, the implementation and the failure cases. **Internal** means evidence from its original implementation, not independent validation. **Draft** means the guide still needs implementation or host testing. Read the evidence section before treating a pattern as proven.

The catalog below is generated from the recipe pages themselves. For the format and evidence standards, see [How to use these recipes](/docs/format).
